# M1-06: DT1 / DS1 map preview

2026-10-07, `feat/m1-legacy-assets`. DT1/DS1 기본 파서·지도 조립·충돌 정보·뷰어와 합성 검증을 구현했다. 실제 LoD 1.10f 지도 인수는 아직 열려 있으며 M1 전체 완료나 게임 플레이 구현을 뜻하지 않는다.

## 구현과 경계

- `Dt1Tileset`: 버전 7.6의 타일/블록 테이블, signed 블록 좌표, 0x0001 등각 픽셀과 0x1001/0x2005 RLE를 읽는다. 입력을 소유하고 원본 높이를 수정하지 않는다. 반복 디코딩의 픽셀과 좌표가 동일하다. 방향·재질·roof height·타일 키·rarity/frame 값·25개 충돌 플래그를 보존한다.
- `Ds1Map`: 버전 1..18의 조건부 헤더, 실제 크기(+1), wall/orientation/floor/shadow/tag 스트림, 레거시 방향 변환, 파일 참조, 오브젝트, 치환 그룹, NPC 경로를 읽는다. 셀의 원본 uint와 방향 uint를 보존한다. 파일 참조는 메타데이터이며 자동 파일 접근에 사용하지 않는다. 모호하거나 연결되지 않은 NPC 경로도 소실 없이 별도로 보존한다.
- `MapScene`: `(main index, sub index, orientation)`으로 사용자가 지정한 DT1 목록과 셀을 연결한다. 첫 번째 일치 타일을 결정적으로 선택하고 중복 수를 알린다. 선택한 타일만 한 번 디코딩한다. missing 타일도 placement로 남겨 화면에서 확인한다. 바닥→하부 벽→그림자→깊이순 상부 벽→지붕 순서의 검사 화면이다.
- 충돌은 DT1 파일의 행 순서를 5×5 x/y로 변환하고 바닥·벽 플래그를 OR한다. bit 0/3은 미리보기의 이동 차단 표시, 다른 비트도 그대로 보존한다. 바닥 정보가 없거나 바닥/벽 타일 연결이 누락되면 `Known=false`다. `BlocksWalk`는 미확인 상태도 차단으로 반환한다. 그림자·지붕은 이동 차단 합산에서 제외한다. 실제 경로 탐색·오브젝트 충돌·게임 판정은 M2 범위다.
- `MapPreview` / `MapCanvas`: 비동기 MPQ 읽기·파싱, 메인 스레드 텍스처 생성, 공유 타일 텍스처, 가시 영역 그리기, 확대·이동, 개별 레이어 표시, 충돌/오브젝트 오버레이, 셀·subtile 플래그 조회. 로드 실패 시 이전 지도를 유지하고 창 종료 후 늦은 완료 결과를 UI에 적용하지 않는다. 맵 전체 크기의 거대 비트맵을 생성하지 않는다. 컨트롤이 화면을 넘으면 Map 탭을 세로 스크롤할 수 있다.
- `AssetAudit --decode`: DT1은 모든 타일 복원, DS1은 구조 검증. `DecoderVersion=m1.06-1`. DS1 validated가 외부 DT1 연결 성공을 뜻하지 않는다. 실제 게임 버전 `unverified`, `Complete=false`를 유지한다.

## 사용법

1. 원본 게임 폴더를 선택하고 **Map** 탭을 연다.
2. DS1 MPQ 논리 경로, 해당 지역의 팔레트 경로, 사용할 DT1 MPQ 경로 목록(한 줄에 하나)을 넣는다. 기본 팔레트는 `data/global/palette/act1/pal.dat`이다. 다른 Act 지도는 올바른 팔레트로 바꾼다.
3. **Load map**을 누른다. DT1 파일 순서가 중복 키 선택 우선순위다. 로딩 직후 missing/duplicate 수를 확인한다.
4. 드래그로 이동하고 휠로 확대한다. 레이어 체크는 표시만 바꾸며 원본 지도와 충돌 데이터는 바꾸지 않는다. **Reset view**로 초기 시점으로 돌아온다.
5. **Collision**: 빨강=이동 차단 비트, 노랑=기타 플래그, 자홍=미확인. **Objects**: 저장된 배치 좌표를 청록 점으로 표시한다. 몬스터/NPC 생성은 실행하지 않는다.

시작 샘플은 직접 생성한 2×2 DS1과 25블록 DT1이다. Blizzard 파일은 코드·CI·배포본에 포함하지 않는다.

## 처리 예산과 제한

| 항목 | 현재 도구 정책 |
|---|---|
| DT1 / DS1 파일 | 각각 최대 32 MiB |
| DT1 | 최대 4,096타일, 타일당 16,384블록, 전체 262,144블록 |
| DT1 픽셀 | 타일 캔버스 최대 4,096×4,096, 파일 전체 캔버스 픽셀 합 16,777,216 |
| DS1 | 각 변 최대 1,024, 전체 65,536셀, 벽 4층·바닥 2층 |
| DS1 부가 데이터 | 참조 256개/문자열 1,024바이트, 오브젝트·그룹·경로 각각 16,384개, 전체 경로 점 65,536개 |
| 지도 조립 | DT1 32파일/전체 8,192타일, 뷰어 누적 입력 64 MiB, 선택 타일 픽셀 합 16,777,216 |

- 이는 지원 범위와 메모리 정책이며 원본 포맷의 절대 최대치가 아니다. 게임 파일 실측 후 정책 조정 여부를 결정한다.
- DT1의 다른 버전/압축 코드, 겹친 payload 범위, 예산 초과는 명시적으로 실패한다. 예약 바이트 및 일부 선언 메타데이터의 의미는 검증하지 않는다. 그림자·지붕 좌표와 특수 벽의 가림 순서는 실제 지도 대조가 필요하다.
- DS1의 잘린 그룹/NPC 꼬리, 지원 범위를 벗어난 버전·Act·치환 타입, 뒤에 붙은 데이터는 거절한다. 원본 C++이 허용하던 불완전 꼬리의 예외 호환은 실파일 근거가 확보되면 별도 추가한다.
- 숨김 셀은 표시·충돌 합산에서 제외하며 해당 구역의 바닥을 확인할 수 없으면 미확인으로 남는다. 미리보기 충돌은 이동 가능성의 최종 판정이 아니다.
- 타일의 가중 무작위 선택, 애니메이션 타일 재생, 자동 DT1 목록 해결, 치환 그룹 적용, 무작위 지도 생성, 특수 corner-wall 대체, PL2 그림자/투명 효과, 실제 NPC·경로 실행은 미구현이다. 태그·그룹·경로는 파싱·보존만 하며 화면에 그리지 않는다.
- 뷰어는 그리기 요청 시 placement 목록을 순회하고 보이는 것만 그린다. 전체 월드 스트리밍, 공간 인덱스, 프레임 예산을 둔 GPU 업로드, 전역 캐시 회수는 이번 단계의 완료 항목이 아니다. 로딩 시 이전/다음 지도 데이터와 텍스처가 일시적으로 공존할 수 있다.

## 검증

- **60/60 계약 테스트 통과**: 기존 40개 + 지도 형식/조립 19개 + MPQ 지도 통합 1개.
- 명시한 예상 픽셀과 비교: DT1 등각 256픽셀, RLE 두 형식의 skip·투명 index·행, signed 블록 union, 입력 사본, 반복 복원, 5×5 충돌 행 방향과 플래그.
- DT1/DS1의 모든 바이트 prefix 잘림, 버전/크기/offset/count/코덱 오류, RLE 행 초과, 데이터 겹침, 누적 픽셀·지도 셀 예산을 검사한다.
- DS1 1..18 버전의 헤더/층 순서/오브젝트 flags/경로 action 분기, raw 셀 비트, 파일 참조·그룹·미연결 경로 보존을 확인한다.
- 타일 공유, 투영 좌표·벽/roof offset, 플래그 OR, 미확인 충돌, 중복 키 선택, 숨김, 누락, 누적 예산을 검증한다. 합성 MPQ에서 지도 로드·감사·손상 보고·원본 불변을 확인한다.
- Linux 전체 Debug 빌드, Godot import·헤드리스 시작·Release export 통과. 헤드리스 시작은 합성 25블록→2×2 지도 조립, 충돌, 텍스처 160×79와 alpha를 확인하고 `OPEND2_M106_MAP_READY`를 출력한다.
- Linux 배포본을 SDK 경로 없이 실행해 기존 시작 마커와 새 지도 마커를 확인했다.
- 원격 OS별 CI 결과는 브랜치 반영 후 이 절에 기록한다.
- 실제 LoD MPQ의 타일·지도 이미지 대조, GUI 마우스/DPI 조작, Windows/macOS 사용자 설치, 큰 지도 성능 실측은 미수행이다.
