# 리소스 및 DLL 이관 설계

## 원본 파일 보존과 전수 목록

원본 MPQ는 사용자가 지정한 위치에서 읽기 전용으로 접근한다. 첫 실행에서 게임 설치 경로를 선택하고 버전·필수 파일·읽기 권한을 검사한다. 사용자의 원본 파일이나 추출 캐시는 Git에 추가하지 않는다. 자동으로 게임 데이터를 내려받지 않는다.

`AssetAudit`는 버전 프로파일별 예상 목록과 실제 아카이브를 대조하여 기계 판독 가능한 보고서를 만든다. MPQ 내부 목록이 불완전할 수 있으므로 아카이브의 listfile만으로 전수 조사가 끝났다고 판단하지 않는다. 테이블 참조·알려진 경로 목록·실제 로딩 기록을 보완한다. 목록을 완전히 확인하지 못한 아카이브는 미확인 상태로 남긴다.

인벤토리 필드: sourceArchive, sourceVersion, logicalPath, contentHash, size, format, decoderVersion, decodeStatus, runtimeStatus, contentId, hdReplacementId, errorCode. 중복 경로는 패치 우선순위에 따라 선택하고 출처를 기록한다. 우선순위는 목표 버전의 실제 데이터로 검증한다.

읽기 및 디코딩 캐시 키는 원본 해시·디코더 버전·변환 옵션으로 구성한다. 캐시는 재생성 가능해야 하며 저장 데이터와 분리한다. UI에는 누락 파일과 미지원 버전을 구분해 표시한다.

## 포맷별 이전 범위

| 범위 | 구현 순서 | 주요 검증 |
|---|---|---|
| MPQ 및 압축 | M1 | 압축 종류·암호화·블록 경계·손상 입력·패치 순서 |
| Palette / TBL | M1 | 색상·투명도·문자열 인덱스·언어별 표기 |
| DC6 | M1 | 방향·프레임·오프셋·투명 픽셀 |
| DCC / COF | M1 | 방향·레이어 합성·장비·애니메이션 타이밍 |
| DT1 / DS1 | M1 | 타일 배치·층·가림·충돌·오브젝트 |
| TXT / BIN 테이블 | M1–M4 | 버전별 스키마·교차 참조·누락 행·값 범위 |
| 음악 / 효과음 / 음성 | M2–M4 | 실제 포함 코덱 조사·반복 재생·언어·채널 |
| 저장 파일 | M2–M4 | 지원 버전 명시·원본 보존·상태 비교 |
| 시네마틱 등 기타 파일 | M4 | 실제 전수 목록에서 포맷 확정·재생 경로 추가 |

표에 없는 형식도 인벤토리에 발견되면 백로그에 추가한다. 초기 OpenD2가 지원하지 않는 시네마틱·특정 언어·데이터도 최종 전체 이관 범위에서 임의로 제외하지 않는다. M1에서 일부를 읽을 수 있다는 사실을 전체 리소스 호환 완료로 표시하지 않는다.

파서는 읽기 길이·오프셋·정수 overflow·할당 크기 상한을 검사한다. 압축 해제 결과 크기에 상한을 두고 경로 탐색으로 원본/캐시 경계를 벗어나지 못하게 한다. 병렬 로딩 수와 캐시 메모리에 상한을 둔다.

## DLL 소스와 빌드 재현성

자체 게임 DLL은 해당 C# 프로젝트 소스로 빌드한다. 원본 Game.exe에 C# DLL을 끼워 넣는 방식이 아니라 독립 실행 파일을 만든다. 원본 D2Game/D2Common 등의 네이티브 ABI 호환은 초기 목표가 아니다.

| 의존성 | 처리 방침 |
|---|---|
| 자체 Core / Assets DLL | 모든 소스·테스트·빌드 설정을 같은 저장소에서 관리 |
| MPQ 네이티브 라이브러리 | StormLib 등 후보의 지원 포맷·플랫폼 검증 후 채택; 커밋 고정·소스 빌드 스크립트·라이선스 포함 |
| Godot 엔진 | 공식 소스와 버전·내보내기 템플릿 해시 기록; 수정 시 포크와 패치·빌드법 추적 |
| 기타 NuGet/네이티브 의존성 | 버전·출처·라이선스·플랫폼·잠금 정보 기록, 불명확한 DLL 반입 금지 |
| Diablerie의 포함 바이너리 | 그대로 복사하지 않음; 필요한 기능의 소스·플랫폼 지원부터 확인 |

네이티브 의존성이 필요하면 안정적인 C ABI와 작은 interop 경계로 제한한다. Windows x64/macOS arm64/Linux x64별 로딩 및 해제 검증을 한다. C#으로 대체할 수 있는지는 포맷 정확성과 성능을 측정한 뒤 결정한다. “C# 이관”이 엔진과 모든 외부 라이브러리까지 C#이라는 의미는 아니다.

예정 파일: `THIRD_PARTY_NOTICES.md`, `eng/dependencies.lock.json`, `eng/build-native.*`. 필요 시 소스를 vendor하거나 고정 submodule로 관리한다. 바이너리만 커밋하여 출처를 잃지 않는다. 해시·컴파일러·빌드 옵션을 기록하며 비트 단위 재현 빌드 성공 여부는 별도로 표시한다.

## 참고 코드와 콘텐츠의 출처

OpenD2의 기존 LICENSE 및 저작권 표시는 유지한다. 다른 저장소에서 가져오는 파일에는 원본 경로·커밋·라이선스·변경점을 기록한다. Godot의 라이선스가 기존 코드의 라이선스를 바꾸는 것은 아니다. Diablerie의 MIT 코드와 게임 리소스를 동일한 권리로 취급하지 않는다.

배포 패키지는 엔진·자체 코드·배포 가능한 콘텐츠를 포함하도록 구성한다. 원본 상용 게임 데이터는 사용자의 설치 파일을 가져오는 방식이 기본이다. 새로운 3D 자산도 제작자·출처·사용 조건을 추적한다. 외부 콘텐츠를 재배포하기 전 허용 범위를 확인한다.
