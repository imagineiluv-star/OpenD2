# PLAY-11 — 원본 HUD 리소스 연결

기준 master: `9ae1fe7` (PLAY-10). 작업 브랜치: `feat/play-11-legacy-hud`.

## 목적과 구현

원본 지형·배우/NPC 아트에 이어 UI 이미지를 플레이에 연결한다. 사용자 소유 LoD MPQ의 DC6 프레임과
팔레트를 명시하고, 실제 체력·기존 메뉴·인벤토리 동작에 연결하는 단계다.

- 선택 `HudArtwork`: 팔레트, 캔버스, Role/경로/frame/X/Y 요소. Decoration 여러 개와 Health/Menu/Inventory 각 최대 한 개.
- 파일명·연속 프레임·배치·팔레트를 추측하지 않는다. 좌표는 프레임의 왼쪽 위이고 DC6 signed offset을 추가하지 않는다.
  같은 파일/프레임은 읽기·디코딩·텍스처를 공유하며 원본의 명시적 opacity를 유지한다.
- 파일당 32MiB, HUD 입력 64MiB, 고유 프레임 4,194,304픽셀, 캔버스 4096×1024·32요소 상한.
  기존 scene 입력 128MiB/전체 픽셀 16,777,216에도 합산한다.
- 입력 배열을 읽기 전에 snapshot으로 복사한다. HUD 설정·소스 해시를 ContentId에 추가하며 HUD 없는 기존 장면의 identity는 유지한다.
  UI 변경 복사본은 별도 체크포인트 슬롯이다. 새 앱은 기존 scene을 읽고 구버전 앱은 새 필드를 거부한다.
- Scene art → HUD artwork settings: 요소 추가/삭제·필드 입력·50% 체력 합성 미리보기·새 복사본 저장·재열기·비활성화.
  데이터 폴더 변경은 재열기를 요구하며 로딩/저장 중 편집을 막는다. 미리보기 실패 시 직전 텍스처를 유지한다.
- 화면 아래 HUD strip: 최대 원래 크기, 가용 폭에 맞춘 비율 유지 축소/중앙 정렬. 체력은 아래쪽 행을 클립한다.
  Menu는 기존 메뉴를 열고, Inventory는 기존 패널 표시를 토글한다. HUD 여백은 동작 영역이 아니다.
  텍스트 HP·상태·기존 메뉴/인벤토리 버튼은 유지한다. 마우스 hit area는 프레임 직사각형이다.
- 모든 HUD 텍스처를 준비하고 기존 지형 준비가 성공한 뒤 적용한다. 장면 실패는 기존 세션을 유지하고 전환/종료 시 텍스처를 해제한다.
- CLI `HudArtworkSources`, 준비 보고서 `HudArtworkConfigured` 추가. 기존 readiness/CLI 종료 코드는 바꾸지 않는다.
  HUD 일부가 구성돼도 원작 전체 UI 완료를 뜻하지 않는다. GUI NOT_RUN·original rules false를 유지한다.
