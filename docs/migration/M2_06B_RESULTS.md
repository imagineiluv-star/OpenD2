# M2-06b1 — 장면 효과음·지역 음악과 음량 설정

기준: master `7aa09f7` / `feat/m2-06b-scene-audio`.
원본 MPQ가 없어 가능한 연결 코드와 합성 검증 범위다. 실제 음원 청취와 M2-06 전체 완료를 뜻하지 않는다.

## 구현과 비용

- 기존 MPQ 우선순위로 PCM WAV를 읽고 scene JSON의 선택 `Audio` 항목에 연결한다. 원본 파일을 수정하거나 배포하지 않는다.
- RIFF/WAVE PCM8/PCM16, 1/2채널, 8~96 kHz를 지원한다. PCM8의 unsigned 샘플은 PCM16으로 변환하고 PCM16 바이트는 보존한다.
- 형식/길이/정렬/청크 중복·패딩을 검증한다. 압축 WAV, IEEE float, extensible, MP3/OGG, smpl 루프 지점은 지원하지 않는다. 다른 원본 형식은 별도 이관 작업이다.
- WAV 입력/디코딩 각각 32 MiB, 오디오 뱅크 입력/PCM 각각 64 MiB, 기존 전체 scene 입력 128 MiB 제한. 청크 최대 1,024개, 효과 최대 6종/각 10초, 음악은 지역당 1곡/최대 8개다.
- 동일 MPQ 경로는 한 번만 읽고 디코딩한다. 같은 PCM/루프 모드의 엔진 스트림을 공유한다. 엔진 복사 메모리는 PCM 예산 외에 추가로 필요하므로 실제 PC RSS 측정은 별도다.
- 효과음 player는 8개 고정, 음악은 1개다. 같은 tick의 같은 cue는 한 번만 재생하고 초과 voice는 순환 교체한다. 거리 감쇠·공간 음향·crossfade·디스크 스트리밍은 미구현이다.
- 공격 시작·피격·사망·드롭/습득·퀘스트 변경·포털 이벤트를 표시 단계에서 소비한다. 파일 읽기/디코딩은 장면 로딩 때만 수행한다. 새 서버 호출이나 게임 tick/RNG 변경은 없다.
- 합성 Camp/Cellar는 직접 생성한 짧은 구별용 톤을 사용한다. 합성 배경음악은 없다. 원본 scene에서 `Audio`를 생략하면 조용한 상태로 기존과 같이 동작한다.
- 지역을 바꾸면 이전 효과/음악을 정지하고 해당 지역 음악 전체를 반복한다. 매핑이 없는 지역은 음악을 정지한다.
- Pause, 숨겨진 Simulation 탭, 창 포커스 상실, 비동기 로드/리플레이 검증 동안 음악을 일시정지하고 효과를 중지한다. 대기열이 없어 복귀 시 과거 효과음이 몰아서 재생되지 않는다.
- New run·checkpoint 로드 시 재생 상태를 초기화한다. 음악 위치는 저장하지 않는다. 노드 종료/뱅크 교체 시 스트림 참조와 리소스를 해제한다.
- 전체/효과/음악 음량 0~100과 음소거를 즉시 적용하고 **Save settings**로 유지한다. 기존 schema 1 파일은 80/80/50·음소거 해제 기본값으로 읽되 저장 전에는 원본을 변경하지 않는다.

오디오는 표현 설정이므로 기존 `ContentId`·게임 상태 hash·저장 슬롯에 포함하지 않는다. 같은 지형/액터에 음원을 추가해도 이전 저장을 사용한다.
검증되지 않은/누락된 음원 매핑은 장면 로딩을 실패시켜 기존 세션을 유지한다. 자료가 준비되지 않았다면 `Audio`를 생략한다.

## 검증

- PCM 변환/바이트 보존, 손상 입력/미지원 형식, 경로·중복·지역 검사, 공유 읽기, 시간/메모리 예산과 저장 호환 계약을 추가했다.
- 기존 rules-v4 독립 상태 벡터와 게임 계약을 계속 검사한다.
- `OPEND2_M206_AUDIO_READY`: 합성 WAV에서 엔진 스트림/loop, 지역 필터·중복 cue 억제·고정 voice 수, Pause/Resume·mute·음량·Stop, 게임 hash 불변을 확인한다. export 후에도 필수다.
- 이 marker는 실제 오디오 장치, 청취 품질, GUI 입력이나 원본 음원 호환을 증명하지 않는다.

로컬 검증: 빌드 오류/경고 0, 게임 계약 **267/267**, 다운로드/패키징 계약 **16/16**, 기존 rules-v4 벡터, Godot headless와 Linux export/배포 실행 검사 통과. 3개 OS 원격 결과는 PR의 검증 기록으로 확정한다. 실제 원본 MPQ·음원, OS 출력 장치, 창 포커스 전환/볼륨/재실행 청취는 **NOT_RUN**이다.
macOS 편집기 초기화/종료 경합 위험은 유지하며 오류 무시 처리는 추가하지 않았다.

## 후속 인수

1. 새 빌드에서 QA-06: 합성 효과음, 전체/효과/음악 음량·mute 저장 및 재실행, Pause/탭/창 포커스 이동 시 잔향/과거 이벤트 확인.
2. 소유한 원본 파일과 실제 경로가 있는 scene으로 QA-09: 효과 이벤트, 지역 음악 전환·loop·무음 지역, 잘못된 WAV 로드 시 기존 세션 유지.
3. 지원하지 않는 원본 오디오 codec 조사·추가, 전체 게임 UI·DPI/다중 모니터와 장시간 실제 플레이.

API 기준: [Godot 4.6 AudioStreamWAV](https://docs.godotengine.org/en/4.6/classes/class_audiostreamwav.html),
[AudioStreamPlayer](https://docs.godotengine.org/en/4.6/classes/class_audiostreamplayer.html). 엔진 버전은 기존 4.6.3 .NET을 유지한다.
