# M2-06a — 플레이 HUD와 표시 설정

기준: PLAY-07 병합 master `b82224a`, 브랜치 `feat/m2-06a-play-hud`.
원본 데이터 없이 가능한 사용자 화면 개선 범위다. M2-06 전체와 실제 GUI 인수는 완료하지 않는다.

## 구현

- Simulation을 기본 탭으로 열고 게임 화면·상태·자주 쓰는 조작을 위에 배치한다.
- HP 숫자와 체력 바, 현재 지역, Playing/Paused/Defeated를 표시한다. 값이 바뀔 때만 HUD를 갱신한다.
- 고정 좌표 패널을 여백/가로 컨테이너와 두 스크롤 영역으로 바꾼다. 최소 창 1000×680이며 확대된 창의 남는 공간을 사용한다.
- 사용하지 않던 회전 큐브와 매 프레임 회전 처리를 제거한다. 게임의 원본/3D 아트 제작은 별도다.
- FPS 30~240, 전체화면/F11, 진단 정보 표시를 즉시 적용한다. Save settings로 저장해야 다음 실행에서도 유지한다.
- 진단 기본값은 숨김이며 Seed·Step·Signal·Verify replay·tick/hash는 Show diagnostics로 표시한다.
- 기존 schema 1 설정에 선택 필드 Fullscreen/ShowDiagnostics를 추가한다. 이전 파일은 창 모드/진단 숨김으로 읽고 원본 파일을 변경하지 않는다.
  기존 설정 백업, 잘못된 설정/미래 버전 덮어쓰기 거절을 유지한다.
- 헤드리스 검증에서는 OS 전체화면 변경을 요청하지 않는다. 표시 설정이 게임 tick/규칙/RNG를 바꾸지 않는다.

## 검증과 한계

새 계약은 기존 설정의 표시 기본값과 원본 바이트 보존을 확인한다. 기존 설정 round-trip/backup 계약은 새 필드까지 검사한다.
로컬 게임 계약 **257/257**, 다운로드/패키징 계약 **16/16**, Linux export·배포 실행 smoke를 통과했다.
`OPEND2_M206_HUD_READY`는 Godot 컨트롤의 체력/일시정지·재개 바인딩과 진단 표시 전환을 검사하며 배포본에서도 필수다.
이 표시는 실제 화면 가독성, 키 입력, DPI나 운영체제 전체화면 전환을 시험한 증거가 아니다.

QA-02/04/06/08에 HUD·진단 전환·표시 설정 저장/재실행을 추가했다.
실제 원본 MPQ/클래스/지역, 일반 사용자 PC GUI, DPI/다중 모니터, 음향·음악은 여전히 미인수/미구현이다.
기존 macOS Godot 편집기 종료 경합 위험도 유지한다. 오류를 무시하는 처리를 추가하지 않았다.

후속: 새 master의 릴리즈 후보 생성 → QA-01~06/08 실제 조작 → 원본 scene 자료가 준비되면 QA-09 → 별도 2시간 QA-10.
