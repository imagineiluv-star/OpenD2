# M2-02 충돌·근접 전투·최소 AI 검증

작성일: 2026-10-08. 작업 저장소: `imagineiluv-star/OpenD2`, 브랜치: `feat/m2-playable-slice`, 병합 대상: `master`. 저장소 ID `1408610348`의 GitHub API `fork: false`를 확인했다. 기존 이력·원본 파일과 마이그레이션 결과를 같은 독립 저장소에 유지한다.

## 변경 이유와 구현 범위

M2-01의 자유 이동에는 지도 충돌과 게임 상호작용이 없었다. 이번 작업은 엔진 독립 시뮬레이션에 충돌·공격·피격·사망·최소 AI를 추가하고 Godot의 Simulation 탭에서 한 캐릭터와 세 몬스터를 조작·검사할 수 있게 한다. 중앙 서버나 신규 외부 패키지는 필요하지 않으며 DLL에 포함되는 자체 코드는 모두 저장소에서 빌드한다.

| 경계 | 실제 구현 |
|---|---|
| Core `CollisionGrid` | 소유 사본의 불변 셀, 지도 밖/미확인 셀 차단, 몸체 충돌, 정수 근접 시야 검사 |
| Assets `MapCollisionGrid` | M1 `MapScene.CollisionAt`의 DS1/DT1 하위 셀을 Core 데이터로 변환 |
| Core `GameSimulation` / `GameCombat` | 체력·쿨다운·피격 정지·사망, 명령 유효성, AI 상태, 결정적 이벤트와 재생 |
| Client `SimulationPreview` | 합성 지도, 방향키 이동, 근접 공격, 체력 표시, 사망 표시, 일시 정지·재생 검사 |
| Tests / validate | 경계·판정·재생·메모리 할당 계약과 `OPEND2_M202_COMBAT_READY` 시작 검사 |

실제 Diablo II 자료 대신 합성 지형과 원을 사용한다. 원본 게임 전투 규칙·캠페인·3D 아트의 완성을 뜻하지 않는다. 기존 M1 리소스 로더·뷰어는 유지하고 충돌 변환 경계만 추가한다.

## 조작

1. **Simulation** 탭에서 지도 클릭 후 방향키로 이동한다.
2. **Space**를 누르고 있거나 **Attack nearest**를 누르면 가장 가까운 살아 있는 몬스터를 공격한다. 지도 밖·회색 벽·보라색 미확인 셀은 이동을 막고, 사거리·시야·쿨다운에 따라 공격이 실패한다.
3. 체력·쿨다운·피격 정지 tick과 공격/사망 결과를 확인한다. 플레이어가 죽으면 **New run**으로 다시 시작한다.
4. **Pause**, **Step one tick**, **Verify replay**로 상태를 검사한다. 같은 seed·초기 지도·승인 입력 기록은 같은 결과를 재생한다. Seed 변경은 **New run**에 적용된다.

## 판정과 예산

- 25Hz, 셀 하나는 256 정수 단위다. DS1 타일 하나는 5×5 탐색 셀이다. 반폭 64의 사각 몸체와 생존 객체끼리의 겹침을 검사한다. 지도 밖과 알 수 없는 타일은 통과를 허용하지 않는다.
- 이동량은 축 32, 대각선 축당 23이다. X 후 Y 순서로 슬라이딩한다. 고정 이동량이 셀/몸체 폭보다 작다는 전제에서 터널링·코너 끼임을 막는다. 고속 돌진·순간이동은 별도 규칙이 필요하다.
- 한 지역의 충돌 세션은 최대 128개 객체다. 지도는 최대 1,048,576셀, 각 축 최대 4,096셀이다. 몸체·AI 탐색은 현재 O(N²)이므로 이 상한을 강제한다. 오픈월드 인원/성능 보장이 아니다.
- 근접 거리는 중심 간 384, AI 감지 거리는 1,536이다. 정수 supercover는 정확한 코너에서 양쪽 셀을 검사한다. AI는 가장 가까운 생존 플레이어를 선택하며 거리 동률은 작은 ID가 우선이다.
- 최소 전투 수치는 플레이어 피해 14~20, 쿨다운 12tick; 몬스터 피해 4~7, 쿨다운 20tick이다. 공격은 객체당 tick당 최대 1회다. 피격 당일의 남은 행동과 다음 3tick 행동을 중단한다. 생존자의 이동 의도는 유지하여 정지가 끝나면 키를 다시 누르지 않아도 이어간다.
- tick 순서: 타이머 → `(Tick, ActorId, Sequence)` 명령 → AI → ID 순 공격 → ID 순 이동 → tick 확정. 같은 tick의 먼저 맞은 객체는 이후 공격을 못 한다. 동시 피해 모델은 아니다. 사망 시 이동·AI 대상을 지우고 몸체 충돌을 해제한다.
- 죽은 객체의 예약 입력은 해당 tick에 폐기하고 새 입력은 거절한다. 실패한 공격은 난수를 소비하지 않는다. 명령 상한은 M2-01의 큐 4,096개/한 tick 128개/미래 250tick을 유지한다.
- 이벤트 공간은 `6 × 객체 수 + 128`로 미리 할당한다. Core의 `Step`에는 엔진·파일 I/O·벽시계·콜백이 없다. snapshot/hash/replay 기록과 화면 갱신은 별도 할당이 있으므로 애플리케이션 전체가 무할당인 것은 아니다.

## 상태 버전

`RulesVersion = 2`. 해시는 기존 상태에 지도 유무·지역·원점·크기·셀, 체력·타이머·종류·AI 모드/대상과 공격 명령 대상을 포함한다. v1 해시는 변경됐다. little-endian 상태를 별도 Python `struct.pack`으로 계산한 기준값을 테스트에서 대조한다.

| fixture | SHA-256 |
|---|---|
| M2-01 이동/입력의 v2 인코딩 | `9c8624135830d3503236d8472dc57b177061ac6140e3e0223781077797e321e7` |
| seed 1, open 10×10 지도, tick 1의 1 HP 몬스터 처치 | `b7a3b7a905558a741514c5bd6434cb5ffd39d845bd92065866a8cbd9eb60c5b5` |

현재 생성자는 초기 상태용이다. 진행 중 snapshot 복원과 버전 있는 저장 포맷은 M2-05 범위다.

## 실제 검증

도구: .NET SDK 10.0.401, Godot 4.6.3 .NET, 고정 StormLib 소스 빌드. 로컬 Linux에서 수행했다.

```sh
python eng/bootstrap.py
python eng/build-native.py
python eng/validate.py --export Linux
dotnet run --project tests/OpenD2.Tests -c Release
env -u DOTNET_ROOT -u DOTNET_ROOT_X64 PATH=/usr/bin:/bin \
  ./artifacts/Linux/OpenD2.x86_64 --headless --quit-after 120 -- --smoke-test
python eng/verify.py
git diff --check
```

- 전체 Debug 솔루션 빌드: 경고 0, 오류 0. Linux self-contained export 및 헤드리스 시작 성공.
- 최종 Release 계약 테스트 **125/125 통과**. 기존 104개와 신규 충돌/전투 21개다. 전체 export 검증의 124개 통과 후 마지막 최대 AI 부하 테스트를 추가했으며, 최종 125개는 Release 실행에서 확인했다. CI는 최종 전체 테스트를 다시 실행한다.
- 벽·미확인 셀·지도 밖·몸체 여백·대각 코너·생존 몸체/시체·극단 좌표·잘못된 spawn/명령을 검사했다. 벽 너머 공격, 동일 tick 중복 공격, 쿨다운·피격 정지, 사망 후 예약 명령, 죽은 대상, AI 거리/동률/공격 주기를 검증했다.
- 1,000tick의 전투 이벤트와 해시가 입력 엔티티 순서 및 40ms 대 7+33ms 렌더 프레임 분할에 관계없이 일치하고 같은 입력 재생과 일치했다.
- 128개 이동 객체 및 64플레이어+64공격 중인 몬스터에서 warmup 100tick 후 1,000tick의 `Step` 관리 할당 **0바이트**를 확인했다. 후자의 로컬 Release tick p99는 **0.233ms**였다. 환경·지형·행동에 따른 참고값이며 40ms 예산을 모든 장비/콘텐츠에서 보장하는 기준은 아니다.
- SDK 환경 변수와 SDK 경로를 제거한 Linux 독립 패키지가 종료 코드 0으로 시작·실행됐고 M0, M1-04~07, M2-01, M2-02의 모든 준비 마커를 출력했다.
- Core/Assets 엔진 미참조 및 신규 마이그레이션 디렉터리의 소스 전용 검사를 통과했다. 게임 MPQ·원본 세이브·추출 리소스·새 DLL 바이너리를 커밋하지 않는다.

## 남은 항목과 다음 작업

1. **M2-03**: 한 마을·한 던전, 지역별 상태·충돌과 전환 실패 시 기존 상태 보존, NPC·퀘스트 한 흐름. 현재 세션은 한 지역이며 스트리밍은 없다.
2. 최소 AI는 직선 추적이므로 벽이나 오목한 지형에서 막힐 수 있다. A*·경로 예산·문/장애물 상태는 후속 구현이다. 군집 회피·고속 이동·스킬·투사체도 아직 없다.
3. 원본 1.10f 게임 데이터가 없어 실제 지형·전투 밸런스와 전 리소스 인수는 미수행이다. DS1/DT1 충돌 연결은 합성 fixture로 검증했다. 원본의 전체 몬스터/스킬/장비 테이블 해석은 별도 작업이다.
4. M2-04 아이템·드롭·장비, M2-05 저장 복원, M2-06 음향·HUD·설치 인수, M3 고품질 3D 아트가 남아 있다. 실제 Windows/macOS 사용자 PC의 GUI 조작·서명·공증·장시간 성능 인수는 CI export와 구분한다.
