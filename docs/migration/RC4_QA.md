# rc.4 후보 준비 — PLAY-08~17 / CI-01

## 실행과 판정

- OS별 새 테스트 프로필, 전체 압축 해제 후 일반 창 실행. 기존 프로필/세이브는 백업하고 원본을 시험에 쓰지 않는다.
- 버전·커밋·플랫폼·패키지 SHA256을 결과에 기록한다. 다른 빌드의 결과를 합치지 않는다.
- 회차별 20분, 실패 재시도 1회 제한을 유지한다. 미완료는 NOT_RUN, 환경/자료 부족은 BLOCKED다.
- 실제 키보드·마우스 입력과 전후 화면, UTC 입력 기록, 게임 로그를 남긴다. 헤드리스 marker는 GUI 증거가 아니다.
- 필수 목록은 QA-01~06, QA-08, QA-11~14다. 모두 PASS이고 증거가 있어야 synthetic_preview 전체 PASS다.
- 이 문서를 생성하는 단계에서는 GUI·원본 자료·2시간 soak 모두 NOT_RUN이다. 봇을 실행하거나 결과를 회수하지 않는다.
