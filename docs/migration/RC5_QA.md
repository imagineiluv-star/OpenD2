# rc.5 후보 준비 — 온라인 서버 패키지 포함

2026-10-12. 계획된 태그: `v0.2.0-rc.5`. 이 문서는 발행 완료 증거가 아니다.
검증된 master에 대해 Release candidate and QA handoff를 실행하고, 생성된 manifest의 실제 커밋과 패키지를 시험한다.
데스크톱 클라이언트의 필수 GUI 시험(QA-01~06, 08, 11~14)은 rc.4와 같다. 이번 후보는 **온라인 서버 패키지**를 함께 배포하며,
온라인 시험 QA-15~18은 아래 별도 절에 따라 **별도 일정**으로 수행한다(필수 목록에 포함되지 않으며 `online_qa_status`로 따로 기록한다).

## 실행과 판정

- OS별 새 테스트 프로필, 전체 압축 해제 후 일반 창 실행. 기존 프로필/세이브는 백업하고 원본을 시험에 쓰지 않는다.
- 버전·커밋·플랫폼·패키지 SHA256을 결과에 기록한다. 다른 빌드의 결과를 합치지 않는다.
- 회차별 20분, 실패 재시도 1회 제한을 유지한다. 미완료는 NOT_RUN, 환경/자료 부족은 BLOCKED다.
- 실제 키보드·마우스 입력과 전후 화면, UTC 입력 기록, 게임 로그를 남긴다. 헤드리스 marker는 GUI 증거가 아니다.
- 필수 목록은 QA-01~06, QA-08, QA-11~14다. 모두 PASS이고 증거가 있어야 synthetic_preview 전체 PASS다.
- 이 문서를 생성하는 단계에서는 GUI·원본 자료·2시간 soak 모두 NOT_RUN이다. 봇을 실행하거나 결과를 회수하지 않는다.

## 온라인 서버 패키지 시험 (QA-15~18, 별도 일정)

릴리스에는 `OpenD2-<버전>-server-<runtime>.zip`이 `linux-x64`, `win-x64`, `osx-arm64`로 포함된다(Intel Mac 서버는 만들지 않는다).
CI가 압축을 푼 서버를 실제로 실행해 TLS, 두 패키지 클라이언트의 게임플레이·재접속, 협동 월드, 네트워크 장애, 32개 스트림 검사를 통과한 뒤에만 포함되며,
`release-manifest.json`의 `server_packages[].validation`에 그 결과가 있다. **실제 두 PC, WAN, 사람이 하는 GUI는 NOT_RUN이다.**
이 절의 시험이 그 빈칸이다. 결과는 `qa-result-template.json`의 QA-15~18과 `server_package_sha256`에 기록하고, 데스크톱 GUI 결과와 합쳐 전체 PASS로 쓰지 않는다.

공통 조건과 정책:
- 서버는 새 폴더에 압축을 풀고 `--data`에 전용 빈 폴더를 준다. 기존 사용자 데이터나 이전 빌드의 `realm.json`을 쓰지 않는다
  (협동 월드 저장은 `cooperative-demo-v1`에서 `v2`로 바뀌어 옛 방이 든 파일은 서버가 시작을 거부하고 원본을 보존한다).
- **일반 클라이언트는 PC당 하나**만 실행된다(두 번째 실행은 안내 후 종료). 따라서 두 번째 클라이언트가 필요한 시험은 **두 번째 PC**가 있어야 한다.
  PC가 한 대뿐이면 해당 시험은 PASS가 아니라 **BLOCKED**로 적고 이유를 남긴다.
- 원격 PC가 접속하려면 신뢰할 수 있는 인증서의 HTTPS 주소가 필요하다. 사설 인증서는 클라이언트의 `Choose private CA`로 공개 루트 PEM만 지정한다.
  평문 HTTP와 인증서 검증 우회는 없다. 상세는 서버 폴더의 `ONLINE_PLAY.md`, `ONLINE_NETWORK.md`, `ONLINE_MODES.md`를 따른다.
- macOS 서버/클라이언트는 서명·공증되지 않았다. 격리 속성 해제 등 우회를 했다면 환경에 기록한다.

주의: 이 절은 합성 Camp/Field 콘텐츠와 합성 퀘스트 한 개를 시험한다. 원본 MPQ 월드, 원본 세이브는 시험 대상이 아니며
PASS가 원작 규칙 호환을 뜻하지 않는다. 실제 장시간 서버 운영, 용량 한계, 패킷 손실은 이 시험으로 입증되지 않는다.
직업·레벨·스킬은 서버 규칙·API와 Open 파일 형식 4까지만 구현되어(preview 표, 원본 값 아님) 클라이언트에 직업 선택·능력치/스킬 창이 없으므로 GUI 시험 대상이 아니다([설명](CHARACTER_PROGRESSION.md)).

## 선택 자료·기기 인수

- QA-09: 소유한 LoD MPQ와 실제 검증된 scene JSON으로 지도 생성(PLAY-08), 배우/Guide/HUD/아이템 아트(09~12), TXT 참조/크기(13~14)를 시험한다. 상세 절차는 GROK_TASK.md와 LEGACY_PLAY_SETUP.md를 따른다.
- 원본 자료가 없으면 BLOCKED다. 원본 파일/추출물을 공개 저장소·결과에 올리지 않는다. 원본 규칙 인수는 false다.
- macOS universal 아카이브의 arm64 CI 통과는 Intel Mac 실행 인수가 아니다. Intel Mac·실제 GPU·서명/공증 설치·오디오 청취·DPI는 환경별 기록이 필요하다.
- QA-10 2시간 일반 창 플레이는 별도 시험이다. 20분 기본 시험이나 빠른 tick 반복으로 대체하지 않는다.

## 자동 검증과 남은 일

CI-01의 모든 ERROR 실패 정책, macOS 12 cold imports + 12 exports, 게임 계약과 실제 OS export,
압축 생성→새 디렉터리 해제→headless smoke를 유지한다. 이 성공은 위 GUI 결과를 PASS로 바꾸지 않는다.

이후: 후보 실행/발행 → 세 OS GUI 결과와 증거 회수 → 실패 수정 → 원본 자료·장시간 인수.
현재 원본 세이브는 헤더 사전검사까지이며 캐릭터/아이템 본문 변환은 별도 미완료다.
