# PLAY-17 — 바닥 이름과 선택 접근/줍기

기준: master `84327fd64b0c0df4c4134935eb7043488ab4d04a` (CI-01 병합 후).
브랜치: `feat/play-17-ground-items`.

## 동작

- 현재 지역·화면 안의 바닥 아이템을 ID 순서로 배치한다. 장비와 물약이 같은 위치에 있어도 이름 상자를 겹치지 않게 위/아래로 이동한다. 연결선으로 바닥 위치를 표시한다.
- 클릭한 이름의 **ItemId**를 유지해 기존 경로 탐색으로 접근하고, Core의 줍기 거리/벽 조건을 만족하면 이동을 멈추고 해당 아이템에 한 번만 Pickup을 제출한다. Core가 가방 공간·소유권·상태를 최종 판정한다.
- 이름은 지형/배우/지붕 위에 표시하는 선택용 오버레이다. 원본 바닥 아트의 깊이 가림이나 원작 품질색 규칙을 구현한 것은 아니다.
- 이름과 클릭 영역을 같은 계산으로 만들며 입력 때도 다시 계산한다. 이미 주운 아이템·다른 지역·화면 밖·숨긴 이름·화면에 완전히 넣을 수 없는 이름은 클릭 대상이 아니다. 공간 부족으로 생략된 항목은 카메라 이동/다른 아이템 줍기 후 다시 배치된다.
- **L / Loot names**로 숨김, **우클릭**으로 경로 취소. 방향키·새 이동/공격/상호작용·포커스 상실·메뉴/Escape·일시정지·새 세션·지역 이동·사망도 대기 중인 접근을 취소한다.
- **F / Pick up nearest**는 기존의 가까운 아이템 즉시 줍기다. 선택 접근을 취소한 뒤 현재 가까운 ID를 제출하며 자동 접근 기능으로 바꾸지 않았다.
- 대상 상태가 바뀌거나 경로가 없으면 중단한다. 기존 25 tick 막힘 제한을 이용한다. 가방 부족 등의 실패는 메시지를 표시하고 자동 재시도하지 않는다.

Core 게임 규칙·저장 schema 4 / rules 7·아이템 ID·RNG·아트 설정 형식은 변경하지 않았다. 경로와 선택은 세션 UI 상태이며 저장하지 않는다.

## 자동 검증

`GroundItemSmoke`는 실제 클라이언트의 이름 클릭 이벤트와 경로 추종/명령/tick을 사용한다.
동일 위치 장비/물약 선택 구분, 겹침 제거, 숨김/좁은 화면/화면 밖/제거 후 hit box,
선택 접근 후 정지, 기존 F 줍기, 재생 hash, 취소 입력/메뉴/포커스/새 세션,
이미 주운 대상, 도달 불가, 25 tick 막힘, 가방 부족의 1회 제출, 포털 지역 이동을 확인한다.

`OPEND2_PLAY17_GROUND_READY`를 프로젝트 smoke와 export/압축 해제 패키지 smoke 모두에서 필수로 검사한다.
CI-01의 모든 ERROR 실패와 macOS 편집기 12회 cold import + 12회 export 반복 검사도 유지한다.
최종 세 OS 실행·병합 후 master 실행·아티팩트 결과는 이 변경의 PR 검증 기록에 링크한다.
