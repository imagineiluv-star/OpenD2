# M2-06c — 가방·장비 패널과 장면 재사용

기준 master `a322fc2`, 브랜치 `feat/m2-06c-player-panels`.

- 기존 드롭다운을 무기/방어구 2칸과 가방 8칸 버튼으로 교체했다. 슬롯·아이템 이름과 선택 항목의 피해 보너스/방어 수치를 표시한다.
- 선택은 아이템 ID를 따른다. 장착 후에도 같은 아이템을 선택하고, 버리거나 새 게임을 시작하면 선택을 해제한다. 빈 슬롯과 선택 상태에 맞지 않는 장착/해제/버리기는 비활성화한다. 장착품은 먼저 해제해야 버릴 수 있고, 가방이 가득 차면 해제를 비활성화한다.
- UI는 기존 Submit→tick→Core 결과를 표시한다. 인벤토리를 직접 변경하거나 원본 아이템 규칙을 추가하지 않았다. 최대 10개 버튼을 재사용한다.
- New run, 합성 장면 전환, 원본 장면 선택/재사용에 확인창을 추가했다. 확인 중 일시정지하며 취소 시 이전 Pause 상태로 돌아간다. 기존 checkpoint 파일은 삭제/덮어쓰기하지 않는다.
- 성공적으로 읽은 scene JSON 경로를 기억하고 **Load remembered scene**으로 다시 불러온다. **Save settings**를 눌러야 다음 실행에서도 유지된다. 실패한 경로는 기존 기억 경로를 바꾸지 않는다.
- `LastScenePath`는 기존 schema 1에 빈 문자열 기본값으로 추가했다. 길이/제어 문자/null을 검사하며 파일 존재를 시작 조건으로 요구하지 않는다. 시작 시 원본 파일을 자동 로드하지 않는다. 게임 MPQ 경로는 기존 설정을 사용한다.

## 검증

기존 설정 round-trip/백업과 이전 파일 기본값 검사를 확장하고, 잘못된 scene 경로로 정상 설정 파일을 덮어쓰지 않는 계약을 추가했다.
`OPEND2_M206_PANELS_READY`는 합성 snapshot을 이용해 실제 장착/버리기 명령의 tick 결과가 슬롯·선택·버튼 상태에 반영되는지 확인하며 export 후에도 필수다.
이 검사는 실제 마우스·키보드·화면 배치/가독성을 검증한 증거가 아니다. 로컬 빌드 오류/경고 0, 계약 **268/268**, 패키징/다운로드 **16/16**, 기존 상태 벡터와 Linux export/배포 실행 검사를 통과했다. 3개 OS 원격 결과는 PR에 기록한다.

## 실제 GUI 확인과 남은 범위

QA-03: 아이템 습득→가방 선택→능력치 확인→장착→장비 슬롯에서 같은 항목 확인→해제→버리기. 빈 슬롯·버린 항목으로 조작 불가 확인.
QA-06: 진행 중 New run의 취소/확인, Pause 상태에서 취소, 키보드 포커스와 1000×680 이상 창의 스크롤 확인.
QA-09: 성공한 원본 장면→Save settings→종료/재실행→Load remembered scene. 파일 이동/손상 시 기존 세션 유지와 새 경로 재선택 확인.

원본 MPQ와 실제 GUI가 없어 위 사용자 조작은 **NOT_RUN**이다. 게임 시작 메뉴·캐릭터 생성/선택·스킬창·원본 격자 크기/아이템 아이콘·드래그 배치는 별도 구현이다.
원본 장면의 경로/좌표/애니메이션 방향을 자동 생성하는 기능도 아직 없다. 이번 작업은 검증된 scene 파일을 재사용하는 단계다.
기존 `v0.2.0-rc.2`에는 오디오와 이번 패널 변경이 포함되지 않는다.
